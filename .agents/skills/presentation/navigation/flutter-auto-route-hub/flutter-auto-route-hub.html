Flutter AutoRoute Navigation Hub

# 1. Overview & Architectural Foundations

This skill serves as the central root coordinator for all application routing and navigation using auto_route. It enforces strict Clean Architecture presentation boundaries, type safety, single-instance router configuration, and routes agents to specialized navigation sub-skills.

Core Navigation Laws (per AGENTS.md):

  1. Strict Presentation Boundary:
  2. BuildContext, context.router, AutoRouter, and navigation calls MUST stay strictly within Presentation widgets, BlocListener callbacks, or specialized UI Navigation Adapters.
  3. Domain and Data layers MUST NEVER import auto_route or manage navigation states.
  4. Composition Root Single Instance:
  5. Instantiate AppRouter ONCE at the application composition root or inject via injectable/get_it.
  6. Pass MaterialApp.router(routerConfig: appRouter.config(...)) at the top level — NEVER instantiate AppRouter inside a widget's build() method.
  7. Type-Safe Route Calls:
  8. NEVER use raw string navigation (pushNamed('/details')).
  9. Pass data strictly using generated *Route constructors (context.router.push(UserDetailsRoute(id: '123'))).
  10. Lightweight Route Arguments:
  11. Pass primitive IDs or lightweight Value Objects in route arguments. Never pass heavy, mutable entity trees across route boundaries; let destination screens fetch their own state.
  12. Code Generation:
  13. After updating route annotations (@RoutePage, @AutoRouterConfig), re-generate routing files using flutter pub run build_runner build --delete-conflicting-outputs.

    Sub-Domain Target Sub-Skill When to Consult
    Core Routes & Parameters flutter-auto-route-core ↗ @AutoRouterConfig, @RoutePage, push/replace/pop/maybePop, @pathParam, @queryParam, transition animations, and AppRouter configuration.
    Nested Tabs & Shells flutter-auto-route-nested-tabs ↗ AutoTabsRouter, AutoTabsScaffold, bottom navigation bars, preserving tab states, popping nested stacks to root, and nested StackRouter scoping.

    UI Presentation Hub flutter-ui-hub ↗ Main UI design system and screen layout decomposition.
